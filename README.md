# 證據，連向質疑

師培生在知識翻新環境中的 SDGs 教學反思與調適歷程　研究成果網站

陳美如　國立清華大學教育與學習科技學系　教授
陳奕安　國立清華大學教育與學習科技學系　博士生

## 關於本研究

以認知網絡分析（Epistemic Network Analysis, ENA）檢視 48 位師培生在 SDGs 教學實踐後的同儕互評語料，共 567 個編碼段落、7 個回饋脈絡。研究關心的不是師培生說了什麼，而是證據、質疑與調適如何被連在一起。

主要發現有三：反思證據被大量援引（學生學習表現占 58.2% 的段落），但明確標定教學預期與實際落差者僅 16.8%；整體平均網絡以學生證據為結構核心，連結強度前十名中有七項與其相關；觸及學習本質的回饋僅 10.2%，兩組師培生的區辨連結型態有所不同。

組間結構差異與回饋書寫量高度混淆，屬探索性觀察而非已確立的結論，詳見網站「誠實揭露」一節。

## 網站結構

單頁式捲動網站，無建置流程，無外部相依套件。

```
index.html            全部版面與程式碼
assets/photos/        課程照片（已去識別化）
assets/video/         課程影片（已去識別化）與封面圖
assets/figs/          ENA 圖表與課程模組圖
assets/manifest.js    圖庫清單
```

本機預覽：

```bash
python3 -m http.server 8000
```

## 影像去識別化

課程照片與影片中的人臉，以及桌上姓名牌等可辨識文字，已於發布前以自動偵測方式遮蔽：

- 人臉：macOS Vision `VNDetectFaceRectanglesRequest`，配合切磚偵測與人體上半身框補強
- 姓名文字：Vision OCR 切磚辨識，濾除機構與場地字樣後遮蔽疑似人名者
- 影片逐幀處理，每三幀重新偵測一次

自動偵測不保證完整。若發現任何未遮蔽之可辨識資訊，請來信告知，將立即移除。
